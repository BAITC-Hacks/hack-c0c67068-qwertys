# hack-c0c67068-qwertys

Hackathon team repository for QwertyS — HackAlem AI 2026.

## Задача

Agentic AI-система для прогнозирования почасовой выработки ВЭС (2 турбины, Шелекский коридор, Алматинская обл.) на горизонте 24–48 часов.

- Обучение: 10-минутные SCADA-данные 11.03.2023 – 31.01.2026 (скорость ветра, нормализованная мощность, температура).
- Тест: 01.02.2026 – 28.02.2026, ежедневный перезапуск прогноза «как в прошлом» — только на архивных прогнозах погоды, доступных на момент выпуска.

## Статус

🚧 В разработке. Анализ данных и источников погоды: [docs/analysis.md](docs/analysis.md).

## Старт и связь команды

Начните с [coordination/START_HERE.md](coordination/START_HERE.md). Координационная ветка: `coord/hackalem-start`.

Здесь находятся роли, сроки, лимиты, исследовательские вопросы, задания агентам и протокол совета идей под руководством Claude. Стартовый пакет содержит планирование и ранее опубликованный анализ; реализация и результаты голосования ещё не подтверждены. Выводы `docs/analysis.md` подлежат проверке по [реестру доказательств](coordination/RESEARCH.md).

Исходные CSV, ключи и большие коллекции навыков в стартовый пакет не включены. Каждый участник получает разрешённые исходные данные из материалов хакатона и сверяет их с `coordination/DATA_MANIFEST.json`.
