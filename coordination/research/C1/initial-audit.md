# Первичный независимый аудит C1

Источник: отчёты действующего Codex в задаче «Проанализировать кейсы хакатона», полученные координатором перед стартовым коммитом 23.09.2026. Это запись сообщённых C1 результатов; координатор не повторял сетевые эксперименты. Сырые ответы, команды и скрипты C1 должен опубликовать отдельно в пределах правил данных.

## Что C1 сообщил как непосредственно проверенное

- Оба Google Maps shortlink из кейса перенаправляют на43.645150,78.535604 и43.643198,78.538828.
- Числа строк142360/149499, конец31.01.2026 23:50, отсутствиеNaN/дублей и февральского факта подтверждены.
- Почасовые корреляции между турбинами: мощность0.970, ветер0.994.
- Бесплатный ECMWF Single Runs GET для обеих координат на31.01,15.02,28.02.2026 с run00Z и forecast_hours72 далHTTP200, по72почасовых значения безnull.
- Обе координаты API преобразует в одну сеточную точку43.620384,78.47891; массивы погоды идентичны. Не изображать две независимые погодные модели.
- Высота555м относится к разрешённой API местности; не считать её паспортной высотой мачты.

## Важные ограничения

C1 сверил официальную историю ECMWF: цикл49r1 был операционным в феврале2026. Это уменьшает подозрение к термину hindcasts в документации, но ещё требует фиксации происхождения конкретных полей архива. HTTP200 не доказывает историческую публикацию.

Инициализация00UTC обычно становится доступна позднее, примерно через4–6часов. Для issue_time00UTC нельзя использовать такой же run00UTC. Конкретное правило available_at/запас должно быть документировано и проверено.

UTC+6 остаётся inferred. Непрерывный ряд через перевод гражданского времени01.03.2024 поддерживает фиксированные системные часы. Проверка ERA5 по10окнам показала лучшие сдвиги ветра+5/+6, температуры+6летом/+7зимой. Это не заменяет исходные метаданные; нужна чувствительность к±1часу. Не использовать timezone часов хакатона как timezoneSCADA.

Февральских фактических лагов нет. Нельзя обновлять модель по отсутствующему факту. Для выпуска31января нельзя использовать наблюдения позднее выбранного момента выпуска даже в пределах того же дня.

Другие числа dev1 — RMSE/смещенияNWP, распределение направлений, автокорреляции — пока заявленные выводы без воспроизводимых материалов в репозитории.
