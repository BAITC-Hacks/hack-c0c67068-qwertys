## API бюджет

Владельцы публикуют только доступность и разрешённый лимит, без ключей/персональных платёжных данных. Денежный cap пока `UNSET`, платные облачные машины не запускать автоматически. Рекомендуемое распределение подтверждённого общего бюджета: до60% разработка и тесты,20% demo,20% резерв. Совет использует существующие подписанные агентные сессии и не открывает платный API-fanout по умолчанию.

Лимиты совета: до4 реальных участников-агентов одновременно (Claude + существующие C1/C2/C4), до12 экспертных перспектив как помеченные роли, до50 исходных идей, до8 финалистов. Максимум20мин и абсолютный предел14:35. При API-исполнении, только после утверждения cap: максимум12 вызовов и суммарный целевой потолок30000 входных+выходных токенов, меньший предел по доступному бюджету имеет приоритет. Точное потребление подписочных сессий этим числом не гарантируется; ограничения по времени/числу ответов обязательны.

Не вызывать LLM для каждой строки SCADA/каждого прогнозируемого часа. Табличная обработка, обучение и метрики выполняются пакетно. Новая модель или фреймворк должны либо убрать блокер, либо дать измеримый выигрыш в отведённое время.
