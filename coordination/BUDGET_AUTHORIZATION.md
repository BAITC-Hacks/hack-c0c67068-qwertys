# Разрешённые пользователем бюджеты

Источник: прямое сообщение пользователя в координационной задаче 23.09.2026 около14:23 UTC+5.

- NVIDIA: разрешено использовать до50USD, пользователь указывает браузерный профиль **Magitsian**.
- OpenAI API: отдельно до50USD, профиль Google/Chrome **Ash**.
- Пользователь допускает расход всего каждого бюджета ради результата. Это не требование потратить деньги и не разрешение превысить предел/пополнить/оформить подписку.
- Реальный баланс, применимость кредитов к Brev/Build/NIM, API project, квоты и текущая цена ещё проверяются в официальных панелях. Заявленный бюджет не равен подтверждённому остатку.
- Один общий потолок на сервис для команды, не новый бюджет каждому агенту. Разрешение сохраняется; обычные необходимые вызовы в этих границах не требуют повторного вопроса.
- Координатор расхода и единственный писатель ledger — C2; до его CLAIM другие агенты не запускают конкурирующие платные jobs. Файл ledger: `coordination/resources/C2-budget-ledger.md`.
- Секреты остаются в локальном окружении/разрешённых secrets, не в Git/чатах/логах. Работа только с собственным разрешённым аккаунтом. Доступ через браузер проверяется по фактическому профилю, не по догадке.

Это разрешение заменяет прежнее `budget UNSET` как вопрос согласия пользователя. Состояние фактически проверенного баланса остаётся UNKNOWN до проверки. Порядок выполнения и ограничение облачных jobs описаны в `C2_START_NOW.md`.
