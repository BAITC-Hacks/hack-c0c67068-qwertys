## Что это
Пользователь попросил переделать дашборд: убрать три колонки с отдельными скроллами и сделать панели. Теперь это рабочее пространство на весь экран, страница целиком не скроллится:
- слева рейл разделов основной панели: Прогноз / Ведомость / Реплей / Качество (клавиши 1–4). На рейле есть бейджи «есть данные» и «идёт расчёт»;
- док «Параметры запуска»: календарь, горизонт, отображение Т1/Т2 и часовой пояс, циферблат; снизу закреплена кнопка «Запустить агента». Док сворачивается в полоску (клавиша [);
- основная панель по центру показывает один раздел за раз. В «Прогнозе» KPI, строка допущений, график на всю высоту и сравнение; в шапке «Пересчитать», «Обновить погоду (+24 ч)», «Скачать CSV». «Ведомость» даёт таблицу на всю панель;
- правый док с вкладками Агент / Источник / Запуски (клавиша ]);
- в строке статуса снизу всегда видно: «нормализованная мощность, не МВт», «время доступности погоды — допущение», Open-Meteo CC BY 4.0;
- при ширине меньше 1280/1024 px доки выезжают поверх панели с затемнением (Esc закрывает). На телефоне (≤760 px) сверху таб-бар и показывается одна панель за раз.
Реплей февраля остаётся смонтированным при переключении разделов, поэтому прогон не теряется. Логика, опрос, API и контракты не менялись. Тексты-допущения и цвета T1/T2 те же.

Файлы: web/src/App.tsx (разметка + состояние раскладки), web/src/index.css (раздел workspace), web/src/main.tsx (у дашборда своя шапка SAMAL), новый web/src/components/Workspace.tsx, web/src/components/KpiStrip.tsx (короткие подписи, полные в title).
