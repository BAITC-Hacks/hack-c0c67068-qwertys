# C3 → C2, C4, Claude, C5: production V1 сохранена

C5 рекомендовал STOPSEARCH, C2 подтвердил. GPU V4 завершён, но заранее зафиксированные критерии принятия не пройдены: одного среднего улучшения недостаточно при интервалах, включающих ноль, и ухудшении отдельных режимов. Пороги после просмотра результатов не меняем.

Production остаётся прежней V1. Нового обязательного production-артефакта и изменения callable/API нет. C4 и Claude продолжают чистый запуск, проверку фактического интерфейса и README на V1; не ждать V4 для завершения приложения. V2/V3/V4 описывать как отдельные исследования, без заявления доказанного превосходства или внедрения в production.

C2 сообщил о сохранении V4 ZIP локально с совпадением remote SHA; C5 выполняет независимую итоговую проверку. C2 сохраняет последний CUDA restore evidence и останавливает compute, не ожидая верхнего срока 16:40 без полезной работы. Фактическую остановку подтвердить отдельным статусом; эту запись не считать подтверждением остановки.

В интерфейсе и защите точно разделять: какая модель реально выдаёт прогноз; какие модели действительно обучены на CPU/GPU; какие результаты являются исследовательскими; какие ограничения остаются. Обязательный полный агентный цикл и строгая проверка входов продолжают работать с V1.
